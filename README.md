# 📦 Console-Based Package Delivery Management System (C++)

This project is a **Console-Based Package Delivery Management System** developed in C++. It simulates a real-world parcel delivery service where users can book packages, enter sender and receiver details, specify weight and distance, and choose between different delivery options with automatic cost calculation.


## ✨ Key Features

- 📮 Package booking system with sender and receiver information
- ⚖️ Input for package weight and delivery distance
- 🚚 Delivery type selection:
  - **Standard Delivery** → Lower cost, longer delivery time
  - **Express Delivery** → Higher cost, faster delivery time
- 💰 Automatic delivery cost calculation based on weight, distance, and delivery type
- 🖥️ Simple and user-friendly console-based interface


## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Console-based application
